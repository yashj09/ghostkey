# AI usage

ETHGlobal asks for clear attribution of AI-assisted work, and this file provides it. GhostKey was built by one person directing **Claude Code** (Anthropic). The AI wrote most of the code; the human set the direction, made the decisions, and reviewed and ran everything.

## How the work was split
| Area | AI | Human |
|---|---|---|
| Idea research (PQ, privacy, Hyperliquid; prior art; sponsor fit) | Ran the web research, compared options, stress-tested both finalists ("Quantum Canary" vs "Ghost Swap") | Chose the direction, pushed back on a generic idea, picked GhostKey + Canary |
| Plan & architecture ([`PLAN.md`](PLAN.md), [`decisions/`](decisions)) | Drafted the plan, ran the protocol spikes, wrote the ADRs | Answered the architecture questions (interface, PQ wallet, remediation, scope, stack, sponsors, hosting, canary) and approved the plan |
| Protocol spikes (`contracts/test/spikes`, `contracts/script/spikes`) | Wrote and ran them on a mainnet fork | Reviewed the findings |
| Contracts (`contracts/src/*.sol` except `vendor/`) | Generated | Reviewed the design (immutable PQ key, ERC-7201 nonce, one-way killswitch) |
| TypeScript core (`packages/core`) | Generated by Claude Code, with parallel sub-agents for the scanner and the demo world | Reviewed APIs and results |
| Web app + demo server (`apps/*`) | Generated with shadcn/ui + the ui-ux-pro-max design skill | Chose the UI direction (clean, minimal, shadcn) |
| Rust tools (`tools/bsgs`, `tools/sphincs-signer/src/bin/sphincs-signer.rs`) | Generated | n/a |
| Docs, README, FEEDBACK | Drafted | Reviewed |

Planning artefacts that directed the AI are committed: [`PLAN.md`](PLAN.md), [`decisions/`](decisions), [`architecture/`](architecture) and [`progress/log.md`](progress/log.md).

## Vendored, non-AI code
- `contracts/src/vendor/sphincs/LeanSphincs-SAsm.sol`: the leanSphincs-s verifier from [nconsigny/SPHINCS-](https://github.com/nconsigny/SPHINCS-) (MIT), unmodified.
- `tools/sphincs-signer/src/{lib,hash,wots,fors,scheme,tiers,keyfile}.rs`, `src/bin/lssk.rs`: the upstream Rust signer (MIT), unmodified. Only `src/bin/sphincs-signer.rs` (a CLI wrapper) is ours.
- shadcn/ui components in `apps/web/src/components/ui/` (MIT, generated by the shadcn CLI).
